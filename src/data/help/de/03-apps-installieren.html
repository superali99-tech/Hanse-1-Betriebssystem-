Apps installieren (Nova Store)

Nova Store

Der Nova Store zeigt tausende Apps von Flathub. Suchen Sie eine App, öffnen Sie die Detailseite und klicken Sie auf Installieren. Der Fortschritt wird in Prozent angezeigt; danach erscheint die App im Startmenü.

Berechtigungen

Flatpak-Apps laufen in einer Sandbox. Vor der Installation zeigt der Store, worauf eine App zugreifen darf (Netzwerk, Ordner, Geräte …). Bei weitreichenden Rechten fragt der Store nach. Berechtigungen können später unter Nova Settings → Anwendungen → Flatpak-Berechtigungen geändert werden.

Aktualisieren und Entfernen

Unter Installiert können Apps geöffnet oder deinstalliert werden, unter Updates aktualisiert. Persönliche Daten einer App bleiben in ~/.var/app erhalten.

Bewertungen

Bewertungen stammen vom Open Desktop Ratings Service (odrs.gnome.org) und können in den Store-Einstellungen abgeschaltet werden.

Kommandozeile

Fortgeschrittene können auch flatpak install flathub org.gimp.GIMP oder sudo apt install paketname verwenden.
