Updates und Sicherheit

Nova Updates

Nova Updates zeigt System-Updates (Debian-Pakete, Kernel, Treiber) und App-Updates (Flatpak) gemeinsam an. Alle Updates installieren fragt einmal nach Ihrem Passwort.

Automatische Updates alle 14 Tage

NovaOS sucht alle 14 Tage automatisch nach Updates für das System und für Apps aus dem Nova Store und lädt sie im Hintergrund herunter. Danach erhalten alle Benutzer die Meldung „Update verfügbar“ – bei jeder Anmeldung und alle 4 Stunden, bis der PC neu gestartet wird. Beim Neustart werden die Updates installiert („Updates werden installiert – bitte den Computer nicht ausschalten“), anschließend startet NovaOS normal. Es wird nie ungefragt neu gestartet.

Wer möchte, kann in Nova Updates zusätzlich tägliche Sicherheitsupdates im Hintergrund einschalten oder jederzeit mit Alle Updates installieren sofort aktualisieren. Abstand und Einstellungen: /etc/novaos/updates.conf.

Firewall

Die Firewall (ufw) ist aktiv: eingehende Verbindungen werden blockiert, ausgehende erlaubt. Einstellungen: Nova Settings → Netzwerk → Firewall.

Verschlüsselung

Bei der Installation kann die Festplatte vollständig verschlüsselt werden (LUKS). Das Passwort wird dann bei jedem Start abgefragt.

Secure Boot

NovaOS verwendet den von Microsoft signierten shim sowie den signierten GRUB und Kernel von Debian. Auf den meisten PCs startet NovaOS daher auch mit aktiviertem Secure Boot. Eigene Kernelmodule (z. B. DKMS-Treiber) müssen dann per MOK signiert werden.
