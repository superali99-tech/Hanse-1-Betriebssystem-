Updates und Sicherheit

Nova Updates

Nova Updates zeigt System-Updates (Debian-Pakete, Kernel, Treiber) und App-Updates (Flatpak) gemeinsam an. Alle Updates installieren fragt einmal nach Ihrem Passwort.

Automatische Sicherheitsupdates

Sicherheitsupdates werden täglich automatisch im Hintergrund installiert (unattended-upgrades). Das lässt sich in Nova Updates abschalten. Sie erhalten eine Benachrichtigung, wenn weitere Updates bereitstehen.

Firewall

Die Firewall (ufw) ist aktiv: eingehende Verbindungen werden blockiert, ausgehende erlaubt. Einstellungen: Nova Settings → Netzwerk → Firewall.

Verschlüsselung

Bei der Installation kann die Festplatte vollständig verschlüsselt werden (LUKS). Das Passwort wird dann bei jedem Start abgefragt.

Secure Boot

NovaOS verwendet den von Microsoft signierten shim sowie den signierten GRUB und Kernel von Debian. Auf den meisten PCs startet NovaOS daher auch mit aktiviertem Secure Boot. Eigene Kernelmodule (z. B. DKMS-Treiber) müssen dann per MOK signiert werden.
