Problemlösung

Das System reagiert nicht

Strg+Esc öffnet die Aufgabenverwaltung; hängende Programme können dort beendet werden.

Nach einem Update startet etwas nicht

Im Startmenü des Rechners (GRUB) unter Erweiterte Optionen einen älteren Kernel wählen oder mit Timeshift einen Schnappschuss wiederherstellen.

Grafikprobleme beim Start

Im Startmenü des Live-Mediums sicherer Grafikmodus (nomodeset) wählen.

Fehlerprotokolle

Nova Task Manager → Fehlerprotokolle zeigt Fehler des aktuellen Starts. Im Terminal: journalctl -b -p err.
