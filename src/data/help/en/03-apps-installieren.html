Installing apps (Nova Store)

Nova Store

Nova Store lists thousands of apps from Flathub. Search for an app, open its page and click Install. Progress is shown in percent; afterwards the app appears in the start menu.

Permissions

Flatpak apps run in a sandbox. Before installing, the store shows what an app may access (network, folders, devices …) and asks for confirmation for extended permissions. Change them later in Nova Settings → Applications → Flatpak Permissions.

Updating and removing

Installed lets you open or uninstall apps, Updates updates them. Personal app data stays in ~/.var/app.

Ratings

Ratings come from the Open Desktop Ratings Service (odrs.gnome.org) and can be disabled in the store settings.

Command line

Advanced users can use flatpak install flathub org.gimp.GIMP or sudo apt install package.
