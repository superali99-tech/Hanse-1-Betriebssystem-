The Nova apps

Overview

  • Nova Browser – web browser (Firefox ESR) with tracking protection, password manager, private mode and PDF viewer
  • Nova Files – file manager
  • Nova Store – install apps
  • Nova Updates – system and app updates
  • Nova Settings – all settings
  • Nova Terminal – Linux terminal
  • Nova Notes – notes (Markdown, saved automatically in Documents/Notes)
  • Nova Calendar – local appointments with reminders (iCalendar import/export)
  • Nova Calculator – calculator
  • Nova Media – video and music
  • Nova Photos – view, crop, rotate and resize pictures
  • Nova Task Manager – processes, performance, error logs
  • Nova Help – this help
