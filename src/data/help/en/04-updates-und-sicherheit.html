Updates and security

Nova Updates

Nova Updates shows system updates (Debian packages, kernel, drivers) and app updates (Flatpak) together. Install all updates asks for your password once.

Automatic updates every 14 days

Every 14 days NovaOS searches for updates for the system and for apps from Nova Store and downloads them in the background. All users are then notified (“Update available”) at every login and every 4 hours until the computer is restarted. The updates are installed during the restart, then NovaOS starts normally. NovaOS never restarts on its own.

Nova Updates can additionally install security updates daily, or install all updates immediately. Interval and settings: /etc/novaos/updates.conf.

Firewall

The firewall (ufw) is enabled: incoming connections are blocked, outgoing allowed. Settings: Nova Settings → Network → Firewall.

Encryption

The installer can fully encrypt the disk (LUKS). The password is then asked at every boot.

Secure Boot

NovaOS uses the Microsoft-signed shim and Debian's signed GRUB and kernel, so it boots on most PCs with Secure Boot enabled. Custom kernel modules (e.g. DKMS drivers) must then be signed with a MOK.
