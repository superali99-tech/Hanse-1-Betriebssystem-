Files and network drives

Nova Files

Nova Files is the file manager: copy (Ctrl+C), paste (Ctrl+V), cut (Ctrl+X), rename (F2), move to trash (Del), drag and drop.

Network drives

Type into the location bar: smb://server/share, sftp://user@server or nfs://server/path. Network in the sidebar lists local shares.

Backups

Timeshift creates system snapshots to roll back after a broken update. Back up personal files to an external drive as well.
