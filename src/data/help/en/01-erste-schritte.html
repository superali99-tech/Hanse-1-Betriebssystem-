Getting started

Welcome to NovaOS

NovaOS is a modern operating system based on Debian 13 “trixie” and the KDE Plasma 6 desktop. It is free, open source and collects no data.

The desktop

  • The floating panel at the bottom contains the start menu, pinned apps, the system tray (Wi-Fi, Bluetooth, volume, battery), clock and calendar.
  • Widgets on the right show a calendar, CPU and memory usage and the weather (right-click → Configure to set your location).
  • Windows can be moved, snapped to screen edges, minimized, maximized and closed.

Starting apps

Click the NovaOS logo or press the Meta (Windows) key and type the app name. Right-click → Pin to Task Manager keeps an app in the panel.

Live system and installation

The live system lets you try NovaOS safely; changes are lost on shutdown. “Install NovaOS” on the desktop starts the installer. Disks are only modified after your explicit confirmation.
