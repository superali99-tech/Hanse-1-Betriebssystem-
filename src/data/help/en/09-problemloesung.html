Troubleshooting

The system does not respond

Ctrl+Esc opens the task manager to end hanging programs.

Something fails after an update

Choose an older kernel in the boot menu under Advanced options or restore a Timeshift snapshot.

Graphics problems at boot

Choose safe graphics mode (nomodeset) in the live medium boot menu.

Error logs

Nova Task Manager → Error logs shows errors of the current boot. In a terminal: journalctl -b -p err.
